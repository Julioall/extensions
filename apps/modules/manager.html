Como funcionam as atualizações

Corrections e Dates são extensões independentes. Downloads são ZIPs para instalação manual no Chrome; o Modules não executa código remoto nem instala extensões automaticamente.

O controle “Mostrar atalhos” afeta somente o menu Modules. Não desativa a extensão instalada.
